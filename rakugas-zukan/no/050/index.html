No.050応用スプレッドシート

在庫が減ったら発注メールを下書き

在庫が発注点を下回った品目を仕入先ごとにまとめ、発注メールの下書きを作ります。

こんな時に便利

消耗品や商品の在庫を表で管理していて、発注漏れや発注の手間を減らしたいときに。

応用のポイント

  • いきなり送らず「下書き」にしているので、数量を確かめてから自分で送信できます。
  • 同じ品目の下書きが毎朝できないよう、発注した日を記録する列を足して、発注済みは飛ばすようにすると安心です。
  • 在庫数を No.024「シートが編集されたら動く」で見張れば、減った瞬間に知らせることもできます。

時間削減のめやす

いまの手作業在庫表を見て足りない物を拾い出し、仕入先ごとにメールを書く
1回あたり約20分 × 月4回
GASならほぼ自動（数秒〜1分）
年間約16時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 在庫が発注点以下の品目を仕入先ごとにまとめ、発注メールの「下書き」を作る
function draftOrders() {
  const rows = SpreadsheetApp.openById('在庫シートID').getSheetByName('在庫')
    .getDataRange().getValues().slice(1);                    // 1行目は見出し
  const bySupplier = {};
  rows.forEach(([item, stock, point, qty, mail]) => {        // 品名・在庫・発注点・発注数・仕入先メール
    if (item && mail && stock <= point) (bySupplier[mail] = bySupplier[mail] || []).push('・' + item + '　' + qty + '個');
  });
  Object.keys(bySupplier).forEach((mail) => {
    GmailApp.createDraft(mail, '発注のお願い',
      'いつもお世話になっております。\n下記の発注をお願いいたします。\n\n' + bySupplier[mail].join('\n'));
  });
}

見本のコードです。「〜ID」・列の位置やセル範囲を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
