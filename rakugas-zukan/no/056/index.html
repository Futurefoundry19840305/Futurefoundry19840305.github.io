No.056応用自動実行

大量のデータを分けて処理する

1回6分の実行時間の上限を超えないよう、5分で区切り、1分後に続きから自動で再開します。

こんな時に便利

数千行のデータの一括処理や、ファイルの大量整理が「時間切れ」で止まってしまうときに。

応用のポイント

  • どこまで進んだかを「スクリプト プロパティ」に覚えておき、次の回はそこから始めます。
  • 続きの予約（トリガー）は毎回作り直し、終わったら片づけるので、トリガーがたまりません。
  • No.044「エラー時に自分へ知らせる」と組み合わせると、途中で止まったときにすぐ気づけます。

時間削減のめやす

いまの手作業範囲を区切って何度も実行し直し、どこまで終わったかを手で管理する
1回あたり約10分 × 月2回
GASならほぼ自動（数秒〜1分）
年間約4時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 5分で区切り、1分後に続きの行から自動で再開する
function processAll() {
  ScriptApp.getProjectTriggers().filter((t) => t.getHandlerFunction() === 'processAll')
    .forEach((t) => ScriptApp.deleteTrigger(t));             // 前回の予約を片づける
  const props = PropertiesService.getScriptProperties();
  const sh = SpreadsheetApp.getActive().getSheetByName('データ');
  const last = sh.getLastRow(), began = Date.now();
  let row = Number(props.getProperty('NEXT_ROW') || 2);
  for (; row <= last; row++) {
    if (Date.now() - began > 5 * 60 * 1000) break;           // 5分たったら区切る
    const value = sh.getRange(row, 1).getValue();
    sh.getRange(row, 2).setValue(String(value).trim());      // ここに1行ぶんの処理を書く（例：整形して隣の列へ）
  }
  if (row <= last) {
    props.setProperty('NEXT_ROW', String(row));
    ScriptApp.newTrigger('processAll').timeBased().after(60 * 1000).create();   // 1分後に続きから
  } else {
    props.deleteProperty('NEXT_ROW');                        // 最後まで終わった
  }
}

見本のコードです。自分の環境に合わせて書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
