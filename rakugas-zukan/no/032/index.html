返信していないメールを通知

数日返事をしていない大事なメールを思い出させます。

年間の時間削減
約40時間

こんな時に便利

返信漏れの防止。

時間削減のめやす

いまの手作業受信箱を見返して返信漏れを探す
1回あたり約10分 × 営業日の毎日
GASならほぼ自動（数秒〜1分）
年間約40時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

function reminder(){
  const th = GmailApp.search(
    'is:starred older_than:3d -in:sent');
  if(th.length) GmailApp.sendEmail(
    Session.getActiveUser().getEmail(),'未返信あり',
    th.map(t=>t.getFirstMessageSubject()).join('\n'));
}

見本のコードです。自分の環境に合わせて書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
