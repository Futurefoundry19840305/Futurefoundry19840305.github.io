No.053応用ドライブ

PDFや画像の文字を読み取る

届いた請求書などのPDFを文字に変換（OCR）し、合計金額などをシートに書き出します。

こんな時に便利

紙やPDFで届く書類の金額・日付を、手で打ち込まずに台帳へ入れたいときに。

応用のポイント

  • Apps Script の「サービス」から拡張サービス「Drive API」を追加します。PDFをGoogleドキュメントに変換するときに文字を読み取ります。
  • 読み取りは完璧ではありません。「要確認」の行や金額は、元のPDFと見比べてから使ってください。
  • No.007「添付ファイルをドライブに保存」と組み合わせると、メールで届いたPDFから自動で読み取れます。

コード例

// フォルダのPDFを文字にして、「合計」のあとの金額をシートに書き出す（拡張サービス「Drive API」を追加）
function readPdfs() {
  const sh = SpreadsheetApp.getActive().getSheetByName('読み取り結果');
  const done = DriveApp.getFolderById('処理済みフォルダID');
  const files = DriveApp.getFolderById('PDFフォルダID').getFilesByType(MimeType.PDF);
  while (files.hasNext()) {
    const pdf = files.next();
    const doc = Drive.Files.create({ name: pdf.getName(), mimeType: MimeType.GOOGLE_DOCS },
      pdf.getBlob(), { ocrLanguage: 'ja' });                  // ドキュメントに変換するときに文字を読み取る
    const text = DocumentApp.openById(doc.id).getBody().getText();
    const m = text.match(/合計[^\d]{0,10}([\d,]+)/);
    sh.appendRow([new Date(), pdf.getName(), m ? Number(m[1].replace(/,/g, '')) : '要確認', text.slice(0, 200)]);
    DriveApp.getFileById(doc.id).setTrashed(true);            // 作業用のドキュメントはごみ箱へ
    pdf.moveTo(done);                                         // 読み取ったPDFは処理済みフォルダへ
  }
}

見本のコードです。「〜ID」を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
