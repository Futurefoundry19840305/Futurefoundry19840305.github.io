No.010カレンダー

今日の予定を朝に通知

毎朝、その日の予定一覧をメールで届けます。

時間削減のめやす

いまの手作業カレンダーを開いて今日の予定を確認
1回あたり約5分 × 営業日の毎朝
GASならほぼ自動（数秒〜1分）
年間約20時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

function todayPlan(){
  const ev = CalendarApp.getDefaultCalendar()
    .getEventsForDay(new Date());
  const body = ev.map(e =>
    Utilities.formatDate(e.getStartTime(),'JST','HH:mm')
    + ' ' + e.getTitle()).join('\n');
  GmailApp.sendEmail(Session.getActiveUser().getEmail(),
    '今日の予定', body || '予定はありません');
}

見本のコードです。自分の環境に合わせて書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
