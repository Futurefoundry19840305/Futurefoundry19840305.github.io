No.029スプレッドシート

入力ミスをチェック

空欄や形式の間違ったメールアドレスを見つけて知らせます。

申込データの抜け漏れ確認。

時間削減のめやす

いまの手作業申込データを1行ずつ見て抜け漏れを確認
1回あたり約30分 × 週1回
GASならほぼ自動（数秒〜1分）
年間約25時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

function check(){
  const rows = SpreadsheetApp.getActiveSheet()
    .getDataRange().getValues().slice(1);
  rows.forEach((r,i) => {
    if(!/^\S+@\S+$/.test(r[1]))
      Logger.log((i+2) + '行目のアドレスを確認');
  });
}

見本のコードです。列の位置やセル範囲を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
