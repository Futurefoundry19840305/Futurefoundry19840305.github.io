No.047応用フォーム

予約を受け付けてカレンダーに入れる

フォームの希望日時が空いていればカレンダーに登録し、受付・お断りのメールを自動で返します。

こんな時に便利

面談・相談会・レッスンなど、時間枠の予約を受け付けたいときに。

応用のポイント

  • フォームの回答先スプレッドシートに書き、トリガー「フォーム送信時」で動かします（e.namedValues は質問名で値を取り出せます）。
  • 同時に2人が同じ枠を申し込んでも二重予約にならないよう、ロック（LockService）で1件ずつ処理します。
  • 営業時間外や休業日を断る条件を足すと、より実用的になります。

時間削減のめやす

いまの手作業申込メールを読み、空きを確認して予定を入れ、返信する
1回あたり約8分 × 月20件
GASならほぼ自動（数秒〜1分）
年間約32時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// フォーム送信時：希望日時が空いていればカレンダーに登録し、結果をメールで返す
function onSubmit(e) {
  const v = e.namedValues;                                   // 質問名で値を取り出す
  const start = new Date(v['希望日時'][0]);
  const end = new Date(start.getTime() + 60 * 60 * 1000);    // 1時間枠
  const to = v['メールアドレス'][0], name = v['お名前'][0];
  const cal = CalendarApp.getDefaultCalendar();
  const lock = LockService.getScriptLock();
  lock.waitLock(20000);                                      // 同時送信による二重予約を防ぐ
  try {
    if (cal.getEvents(start, end).length) {
      GmailApp.sendEmail(to, 'ご予約について', name + ' 様\nあいにくその時間は埋まっております。別の日時でお申し込みください。');
      return;
    }
    cal.createEvent('予約：' + name, start, end, { description: to });
    GmailApp.sendEmail(to, 'ご予約を承りました',
      name + ' 様\n' + Utilities.formatDate(start, 'Asia/Tokyo', 'M月d日 H:mm') + ' からでお待ちしております。');
  } finally {
    lock.releaseLock();
  }
}

見本のコードです。自分の環境に合わせて書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
