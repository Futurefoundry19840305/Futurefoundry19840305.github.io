No.046応用Webアプリ

スマホで押せる打刻ボタン

「出勤」「退勤」ボタンだけのページを作り、押した時刻と人をシートに記録します。

年間の時間削減
約6時間

こんな時に便利

小さな事務所やお店の勤怠を、タイムカードや手書きの出勤簿から置きかえたいときに。

応用のポイント

  • 押した人のメールアドレスが取れるのは、Google Workspace の同じ組織の中で使う場合です。個人のGmail同士では、名前を選ぶ欄を足します。
  • ホーム画面に追加しておくと、アプリのように1タップで開けます。
  • 月末の集計は、記録シートからピボットテーブルや No.001 の集計で作れます。

時間削減のめやす

いまの手作業タイムカードや出勤簿を見ながら勤務時間を表に打ち直す
1回あたり約30分 × 毎月の締め
GASならほぼ自動（数秒〜1分）
年間約6時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// ボタンだけのページを返す（スマホでも押しやすい大きさ）
function doGet() {
  return HtmlService.createHtmlOutput(
    '<style>button{font-size:24px;padding:16px 32px;margin:8px}</style>' +
    '<button onclick="p(\'出勤\')">出勤</button><button onclick="p(\'退勤\')">退勤</button><p id="m"></p>' +
    '<script>function p(t){m.textContent="記録中…";google.script.run.withSuccessHandler(function(s){m.textContent=s}).punch(t)}</script>')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}
function punch(type) {
  if (['出勤', '退勤'].indexOf(type) < 0) return '不正な操作です';
  const user = Session.getActiveUser().getEmail();     // 同じ組織の中なら取得できる
  const sh = SpreadsheetApp.openById('勤怠シートID').getSheetByName('打刻');
  sh.appendRow([new Date(), user, type]);
  return Utilities.formatDate(new Date(), 'Asia/Tokyo', 'H:mm') + ' に' + type + 'を記録しました';
}

見本のコードです。「〜ID」を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
