No.023自動実行

毎日・毎週決まった時間に実行

時間を決めておけば、パソコンを閉じていても動きます。

こんな時に便利

毎朝8時にレポート送信、毎週月曜に集計。

時間削減のめやす

いまの手作業決まった時間にレポートを作って送信
1回あたり約10分 × 営業日の毎日
GASならほぼ自動（数秒〜1分）
年間約40時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 画面左の時計マーク「トリガー」から設定もOK
function setTrigger(){
  ScriptApp.newTrigger('todayPlan')
    .timeBased().everyDays(1).atHour(8).create();
}

見本のコードです。自分の環境に合わせて書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
