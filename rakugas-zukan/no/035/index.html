1回の手作業時間と回数から計算した、めやすです。

コード例

function rename(){
  const it = DriveApp.getFolderById('フォルダID').getFiles();
  let n = 1;
  while(it.hasNext()){
    it.next().setName('領収書_' + String(n++).padStart(3,'0'));
  }
}

見本のコードです。「〜ID」を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
