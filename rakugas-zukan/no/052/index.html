No.052応用ドライブ

公開しすぎのファイルを見つける

「リンクを知っている全員」などに公開されている自分のファイルを探し、一覧にします。

こんな時に便利

情報漏えいの点検に。退職者の引き継ぎや、取引先との共有を見直すときにも。

応用のポイント

  • ファイルが多いと1回の実行時間（6分）を超えることがあります。そのときは No.056 の分割処理と組み合わせます。
  • 見つけたファイルの共有をまとめて直すなら No.036 と組み合わせます。まずは一覧で確認してから直すのが安全です。
  • 組織のファイル全体を点検するのは、Google Workspace の管理者向けの機能のほうが向いています。

時間削減のめやす

いまの手作業ドライブのファイルを1つずつ開いて共有設定を確かめる
1回あたり約60分 × 四半期ごと
GASならほぼ自動（数秒〜1分）
年間約4時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 自分がオーナーのファイルのうち、外部に公開されているものを「共有チェック」シートに書き出す
function auditSharing() {
  const out = [['ファイル名', '共有範囲', '最終更新', 'URL']];
  const open = [DriveApp.Access.ANYONE, DriveApp.Access.ANYONE_WITH_LINK];
  const files = DriveApp.searchFiles("'me' in owners and trashed = false");
  while (files.hasNext()) {
    const f = files.next();
    const a = f.getSharingAccess();
    if (open.indexOf(a) >= 0) out.push([f.getName(), String(a), f.getLastUpdated(), f.getUrl()]);
  }
  const ss = SpreadsheetApp.getActive();
  const sh = ss.getSheetByName('共有チェック') || ss.insertSheet('共有チェック');
  sh.clear().getRange(1, 1, out.length, out[0].length).setValues(out);
}

見本のコードです。自分の環境に合わせて書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
