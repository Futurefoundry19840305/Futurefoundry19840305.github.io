No.051応用自動実行

契約の更新日が近づいたら知らせる

契約台帳を毎朝見て、更新日の30日前と7日前に担当者へメールで知らせます。

こんな時に便利

サービスの契約・保守・リース・ドメインなど、うっかり自動更新や期限切れを防ぎたいときに。

応用のポイント

  • トリガー「時間主導型・日付ベース」で毎朝1回動かします。
  • 「何日前に知らせるか」は [30, 7] の部分で自由に変えられます。
  • 更新日の列は日付の形式（例：2026/12/31）で入れてください。文字として入っていると判定できません。

時間削減のめやす

いまの手作業契約台帳を開き、近づいている更新日を目で探して連絡する
1回あたり約20分 × 毎月
GASならほぼ自動（数秒〜1分）
年間約4時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 毎朝：更新日の30日前・7日前になった契約を、担当者にメールで知らせる
function remindRenewals() {
  const rows = SpreadsheetApp.openById('契約台帳ID').getSheetByName('契約').getDataRange().getValues().slice(1);
  const today = new Date(); today.setHours(0, 0, 0, 0);
  rows.forEach(([name, due, owner]) => {                     // 契約名・更新日・担当者メール
    if (!(due instanceof Date) || !owner) return;
    const days = Math.round((due - today) / 86400000);
    if ([30, 7].indexOf(days) >= 0) {
      GmailApp.sendEmail(owner, '【更新' + days + '日前】' + name,
        name + ' の更新日は ' + Utilities.formatDate(due, 'Asia/Tokyo', 'yyyy/M/d') + ' です。継続・解約のご判断をお願いします。');
    }
  });
}

見本のコードです。「〜ID」・列の位置やセル範囲を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
