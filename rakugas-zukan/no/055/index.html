No.055応用外部連携

外部サービスと毎晩データを同期

ネットショップや業務システムのAPIから新しいデータを取り込み、シートを毎晩最新にします。

実行ボタン

実行ボタン▸GAS▸シート▸外部サイト

こんな時に便利

別のサービスの管理画面から、毎日CSVを書き出して貼り付けている作業をなくしたいときに。

応用のポイント

  • アクセストークンは「スクリプト プロパティ」に保存し、コードやシートに書かないでください。
  • 取り込み済みの番号を見て、同じデータを二重に入れないようにしています。
  • URL・ページのたどり方・項目名はサービスごとに違います。使うサービスのAPIの説明書に合わせて書き換えます。

時間削減のめやす

いまの手作業管理画面からCSVを書き出し、シートに貼り付けて整える
1回あたり約15分 × 営業日の毎日
GASならほぼ自動（数秒〜1分）
年間約60時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 毎晩：外部サービスのAPIから注文を取得し、まだ取り込んでいないものだけをシートに追加する
function syncOrders() {
  const props = PropertiesService.getScriptProperties();
  const token = props.getProperty('SHOP_API_TOKEN');         // アクセストークンは設定に保存
  const sh = SpreadsheetApp.getActive().getSheetByName('注文');
  const known = new Set(sh.getRange('A2:A').getValues().flat().map(String));   // 取り込み済みの注文番号
  let url = 'https://api.example.com/v1/orders?since=' + encodeURIComponent(props.getProperty('LAST_SYNC') || '');
  const rows = [];
  while (url) {                                              // ページを順にたどる
    const res = UrlFetchApp.fetch(url, { headers: { Authorization: 'Bearer ' + token }, muteHttpExceptions: true });
    if (res.getResponseCode() !== 200) throw new Error('取得に失敗しました：' + res.getResponseCode());
    const body = JSON.parse(res.getContentText());
    body.orders.filter((o) => !known.has(String(o.id)))
      .forEach((o) => rows.push([o.id, new Date(o.created_at), o.total]));
    url = body.next || null;
  }
  if (rows.length) sh.getRange(sh.getLastRow() + 1, 1, rows.length, 3).setValues(rows);
  props.setProperty('LAST_SYNC', new Date().toISOString());
}

見本のコードです。メールアドレスやURL・トークン・列の位置やセル範囲を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
