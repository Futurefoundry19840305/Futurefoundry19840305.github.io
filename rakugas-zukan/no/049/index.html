No.049応用スライド

月次レポートを自動で作って配る

シートの数字とグラフをスライドのひな形に差し込み、PDFにして関係者へメールします。

実行ボタン

こんな時に便利

毎月の売上報告・定例会議の資料づくりを、数字の転記からなくしたいときに。

応用のポイント

  • スライドのひな形に {{売上}} のような目印を書いておき、replaceAllText で差し込みます。
  • グラフはシートで作っておけば、insertSheetsChartAsImage でスライドに貼れます。
  • No.043「毎月1日に実行」と組み合わせると、何もしなくても毎月届きます。初めは送り先を自分だけにして確かめてください。

時間削減のめやす

いまの手作業数字をシートから資料に書き写し、グラフを貼り直してPDFで送る
1回あたり約90分 × 毎月
GASならほぼ自動（数秒〜1分）
年間約18時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 先月の数字をスライドのひな形に差し込み、PDFにして関係者へ送る
function monthlyReport() {
  const sh = SpreadsheetApp.openById('集計シートID').getSheetByName('月次');
  const [sales, orders, rate] = sh.getRange('B2:B4').getValues().flat();   // 売上・件数・成約率
  const month = Utilities.formatDate(new Date(), 'Asia/Tokyo', 'yyyy-MM');
  const copy = DriveApp.getFileById('ひな形スライドID').makeCopy('月次レポート_' + month);
  const deck = SlidesApp.openById(copy.getId());
  deck.replaceAllText('{{売上}}', Number(sales).toLocaleString('ja-JP') + '円');
  deck.replaceAllText('{{件数}}', String(orders));
  deck.replaceAllText('{{成約率}}', Math.round(rate * 100) + '%');
  deck.getSlides()[1].insertSheetsChartAsImage(sh.getCharts()[0]);         // 2枚目にグラフを貼る
  deck.saveAndClose();
  GmailApp.sendEmail('team@example.com', '月次レポート（' + month + '）', '今月のレポートを添付します。',
    { attachments: [copy.getAs('application/pdf')] });
}

見本のコードです。「〜ID」・メールアドレスやURL・トークン・列の位置やセル範囲を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
