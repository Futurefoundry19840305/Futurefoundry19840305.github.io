No.048応用カレンダー

全員が空いている会議の候補を探す

参加者のカレンダーの空き状況を調べて、全員が空いている時間の候補を一覧にします。

こんな時に便利

3人以上の打ち合わせで、日程調整のメールの往復を減らしたいときに。

応用のポイント

  • Apps Script の「サービス」から拡張サービス「Google Calendar API」を追加すると、Calendar.Freebusy が使えます。
  • ほかの人の空き状況が見られるのは、相手がカレンダーを共有している（同じ組織など）場合です。
  • 見つかった候補を No.009 のように予定として仮登録したり、メールの文面にしたりもできます。

時間削減のめやす

いまの手作業参加者に都合を聞いて回り、空いている時間を突き合わせる
1回あたり約15分 × 月4回
GASならほぼ自動（数秒〜1分）
年間約12時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 参加者全員が空いている30分枠を、これから5日間で5つまで探す（拡張サービス「Calendar API」を追加）
function findSlots() {
  const people = ['a@example.com', 'b@example.com', Session.getActiveUser().getEmail()];
  const from = new Date(), to = new Date(from.getTime() + 5 * 86400000);
  const res = Calendar.Freebusy.query({
    timeMin: from.toISOString(), timeMax: to.toISOString(), timeZone: 'Asia/Tokyo',
    items: people.map((id) => ({ id })),
  });
  const busy = Object.values(res.calendars).flatMap((c) => c.busy || [])
    .map((b) => [new Date(b.start), new Date(b.end)]);
  const slots = [];
  const t = new Date(from); t.setMinutes(t.getMinutes() < 30 ? 30 : 60, 0, 0);   // 次の30分区切りから
  for (; t < to && slots.length < 5; t.setMinutes(t.getMinutes() + 30)) {
    const end = new Date(t.getTime() + 30 * 60000);
    if (t.getDay() % 6 === 0 || t.getHours() < 10 || t.getHours() >= 18) continue;   // 平日10〜18時だけ
    if (!busy.some(([s, e]) => s < end && t < e)) slots.push(Utilities.formatDate(t, 'Asia/Tokyo', 'M/d H:mm〜'));
  }
  Logger.log(slots.length ? slots.join('\n') : '候補が見つかりませんでした');
}

見本のコードです。メールアドレスやURL・トークン・列の位置やセル範囲を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
