1回の手作業時間と回数から計算した、めやすです。

コード例

function highlight(){
  const sh = SpreadsheetApp.getActiveSheet();
  const rows = sh.getDataRange().getValues();
  const today = new Date();
  rows.forEach((r,i) => {
    if(i>0 && r[1] < today)
      sh.getRange(i+1,1,1,r.length).setBackground('#ffd6d6');
  });
}

見本のコードです。列の位置やセル範囲を自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
