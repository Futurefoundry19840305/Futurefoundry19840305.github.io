No.054応用Gmail

問い合わせをAIで分類・要約

問い合わせメールをAI（Gemini API）に読ませて種類分けと1行要約をし、ラベルとシートに残します。

実行ボタン

実行ボタン▸GAS▸シート▸メール▸外部サイト

こんな時に便利

問い合わせ窓口のメールが多く、急ぎ・担当ごとに振り分ける手間を減らしたいときに。

応用のポイント

  • APIキーはコードに書かず、「プロジェクトの設定」→「スクリプト プロパティ」に GEMINI_API_KEY として保存します。キーは公開の場所に置かないでください。
  • メールの本文を外部のAIに送ることになります。お客さまの個人情報の扱いについて、社内のルールや利用規約を確かめてから使ってください。
  • AIの分類はまちがえることがあります。最初は「分類の提案」として使い、人が確かめる運用にします。モデル名は入れ替わります（例：2.5 世代は新しく使い始める人には提供されていません）。使う前に Google の案内で最新の名前を確認してください。

時間削減のめやす

いまの手作業問い合わせを1通ずつ読み、種類を判断して担当に振り分ける
1回あたり約2分 × 月100通
GASならほぼ自動（数秒〜1分）
年間約40時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// まだ処理していない問い合わせメールを、AI（Gemini API）で分類・要約してラベルとシートに残す
const MODEL = 'gemini-3.8-flash';                            // 使うモデル名（Googleの「Gemini のモデル」ページで最新の名前を確認）
function triageMail() {
  const key = PropertiesService.getScriptProperties().getProperty('GEMINI_API_KEY');   // キーはコードに書かない
  const sh = SpreadsheetApp.getActive().getSheetByName('問い合わせ');
  const doneLabel = GmailApp.getUserLabelByName('AI済み') || GmailApp.createLabel('AI済み');
  GmailApp.search('to:info@example.com -label:AI済み newer_than:2d', 0, 20).forEach((th) => {
    const m = th.getMessages()[0];
    const prompt = '次のメールを「見積」「不具合」「請求」「その他」のどれかに分類し、1行で要約してください。' +
      'JSONで {"cat":"","sum":""} だけを返してください。\n\n' + m.getPlainBody().slice(0, 3000);
    const res = UrlFetchApp.fetch('https://generativelanguage.googleapis.com/v1beta/models/' + MODEL + ':generateContent', {
      method: 'post', contentType: 'application/json', headers: { 'x-goog-api-key': key },
      payload: JSON.stringify({ contents: [{ parts: [{ text: prompt }] }], generationConfig: { responseMimeType: 'application/json' } }),
    });
    const ai = JSON.parse(JSON.parse(res.getContentText()).candidates[0].content.parts[0].text);
    const label = 'AI/' + ai.cat;
    th.addLabel(GmailApp.getUserLabelByName(label) || GmailApp.createLabel(label)).addLabel(doneLabel);
    sh.appendRow([m.getDate(), m.getFrom(), m.getSubject(), ai.cat, ai.sum]);
  });
}

見本のコードです。メールアドレスやURL・トークンを自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
