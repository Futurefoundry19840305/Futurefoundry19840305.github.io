No.045応用Webアプリ

申請をメールで承認してもらう

申請が入ると上長に「承認・却下」のリンク付きメールが届き、押すと結果がシートに残ります。

こんな時に便利

備品購入・休暇・経費などの申請を、紙やチャットのやり取りなしで承認まで進めたいときに。

応用のポイント

  • リンクを開いただけで承認されないよう、確認画面のボタンを押して確定する作りにしています（メールのセキュリティ機能がリンクを先読みすることがあるため）。
  • 行ごとに使い捨ての合言葉（トークン）を発行し、一度使ったリンクは無効にします。
  • ウェブアプリは「次のユーザーとして実行：自分」でデプロイし、APP_URL にそのURLを入れます。

時間削減のめやす

いまの手作業申請内容を転送し、返事を待って台帳に書き写す
1回あたり約10分 × 月10件
GASならほぼ自動（数秒〜1分）
年間約20時間の削減

1回の手作業時間と回数から計算した、めやすです。

コード例

// 申請シートの行について、承認・却下のリンク付きメールを上長へ送る
const APP_URL = 'ウェブアプリのURL';
function requestApproval(row) {
  const sh = SpreadsheetApp.getActive().getSheetByName('申請');
  const [date, name, item, amount] = sh.getRange(row, 1, 1, 4).getValues()[0];
  const token = Utilities.getUuid();
  sh.getRange(row, 6).setValue(token);            // F列：使い捨ての合言葉
  const link = (a) => APP_URL + '?row=' + row + '&a=' + a + '&t=' + token;
  GmailApp.sendEmail('boss@example.com', '【承認依頼】' + name + '：' + item,
    item + '（' + amount + '円）\n承認する：' + link('ok') + '\n却下する：' + link('ng'));
}
// リンクを開くと確認画面を出す（開いただけでは確定しない）
function doGet(e) {
  const a = e.parameter.a === 'ok' ? 'ok' : 'ng';
  const row = Number(e.parameter.row) || 0;
  const t = String(e.parameter.t || '').replace(/[^\w-]/g, '');
  return HtmlService.createHtmlOutput('<p>' + (a === 'ok' ? '承認' : '却下') + 'しますか？</p>' +
    '<button onclick="google.script.run.withSuccessHandler(function(m){document.body.textContent=m})' +
    '.decide(' + row + ',\'' + a + '\',\'' + t + '\')">確定する</button>');
}
function decide(row, a, t) {
  const sh = SpreadsheetApp.getActive().getSheetByName('申請');
  if (!t || sh.getRange(row, 6).getValue() !== t) return 'このリンクは使えません（処理済みか無効です）';
  sh.getRange(row, 5).setValue(a === 'ok' ? '承認' : '却下');   // E列：結果
  sh.getRange(row, 6).clearContent();                          // 一度使ったリンクは無効に
  return '記録しました。';
}

見本のコードです。メールアドレスやURL・トークンを自分のものに書き換え、テスト用のデータで試してから使ってください。

試し方

  1. Googleスプレッドシートを開く
  2. メニューの「拡張機能」→「Apps Script」を選ぶ
  3. コードを貼り付けて保存する（Ctrl＋S）
  4. 「実行」を押す（初回だけ許可の確認が出ます）
  5. 自動で動かすなら、左の時計マーク「トリガー」で時間を設定する

うまく動かないときは、使う前に知っておきたいことを確認してください。
